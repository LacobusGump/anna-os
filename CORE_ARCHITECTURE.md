## The Unified Map

```
LOCATION LAYER:
  GPS coordinates → kitchen, office, Route 22
  Temporal patterns → Tuesday 3pm = Shan route
  Movement → leaving office = heading somewhere

AUDIO LAYER:
  Acoustic signatures → stove = cooking
  Voice patterns → stress level, emotional state
  Environmental → location confirmation
  Social → passenger detected

HEALTH LAYER:
  HR + barometer + accel → coupling state
  Baseline variations → stress, recovery
  Sleep patterns → fatigue level

SOCIAL LAYER:
  Texts → who, when, why
  Voice fingerprinting → who's present
  Passenger detection → volume adjust

MUSIC LAYER:
  Which songs work where
  Tempo matching activity + mood
  Lyrics vs. instrumental (social context)
  Duration matching routes

ROUTE LAYER:
  Which paths, when, why
  ETA prediction
  Music that conducts each turn
  Social context

PREDICTIVE LAYER:
  All layers talking to each other
  "Tuesday 3pm + office + text from Shan" → Route 22
  "Stressed + 12min drive + alone" → orchestral
  "Passenger just arrived" → volume -6dB
```

**All ONE map. All reinforcing. All calibrating.**

## The Learning Formula

```
Confidence(context) = 
    (audio_match × 0.30) +
    (gps_pattern × 0.20) +
    (hr_vs_baseline × 0.20) +
    (social_context × 0.15) +
    (time_pattern × 0.15)
```

Each layer weighted equally initially. Over time:
- Recency matters (recent patterns weight higher)
- Accuracy refined (cross-validation: do all 5 agree?)
- Confidence grows (rare surprises, usually right)
