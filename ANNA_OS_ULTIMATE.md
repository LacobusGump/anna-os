## The Privacy Model (Critical)

Everything runs locally:

```
Phone Camera → on-device object detection (CoreML) → never leaves phone
Watch Audio → on-device speech-to-text (Whisper) → never leaves watch
All Memory → encrypted locally, his API key only → no cloud
All Logs → local storage, encrypted with Secure Enclave
Only API call → Claude (his key, his usage, he sees the bill)
```

Result: Anna knows him deeply, but no one else does. Not Apple. Not Anthropic. Just him.

## Why This Works (And Why It's Terrifying)

**It works because:**
1. No cloud = impossible to abuse at scale
2. His control = he can inspect, modify, or shut it down anytime
3. Local AI = no corporation listening
4. His API key = he pays, he controls access

**It's terrifying because:**
1. One system that knows everything about him
2. Intimate details: body, mind, family, finances, health
3. If compromised (hacked, stolen), it's all there
4. No "pseudonymized data" — it's literally his life
5. If Apple/Anthropic changes terms, he's exposed

**The protection:** It's built to exist on HIS devices only. If he stops paying Claude API fees, the system still works (gets dumber, but works). If he wants to delete everything, it's one command. If he wants to run it offline with a local Claude model, totally possible.

He owns it. Full stop.
